# 中文排版细则

本文所有数字都是**实测**：PowerPoint 16.0 COM，`TextRange.BoundWidth/BoundHeight`，
微软雅黑 20pt，单位磅。

## 1. 一个汉字 = 一个字号宽

| 对象 | 实测 | 相对字号 |
|---|---|---|
| 一个汉字「中」 | 20.0 pt | **1.00 em** |
| 全角逗号「，」 | 20.0 pt | 1.00 em |
| 拉丁字母（ABCDE 平均） | 13.3 pt | ≈0.66 em |

于是「一行能放几个字」可以直接算：

```
每行字数 = 框宽(pt) / 字号(pt)
```

10 in 画布、边距 0.55 → 内容宽 8.9 in = 640.8 pt：

| 字号 | 每行字数 |
|---|---|
| 15 pt（正文） | 42 |
| 24 pt（lead） | 26 |
| 54 pt（标题） | 11 |

**54pt 标题一行最多 11 个中文字。** 超了必折行——所以封面标题要主动写成两行，
而不是让生成器去折，否则断点会落在很难看的位置。

## 2. 行距：百分比不是字号倍数

最容易搞错的一条。实测 3 行 20pt 文字：

| `spcPct` | 行高 | 相对字号 |
|---|---|---|
| 100000（默认单倍） | 24.0 pt | **1.20×** |
| 83333 | 19.9 pt | **1.00×** |
| 150000 | 36.0 pt | **1.80×** |

换算公式：

```
行高倍数 = spcPct / 100000 × 1.2
spcPct  = 想要的倍数 / 1.2 × 100000
```

速查：

| 想要行高 | 写 `spcPct` | python-pptx |
|---|---|---|
| 1.00×（标题压紧） | 83333 | `line_spacing = 0.833` |
| 1.05× | 87500 | `0.875` |
| 1.20×（默认） | 100000 | `1.0` |
| 1.50×（正文推荐） | 125000 | `1.25` |
| 1.75×（长文） | 145833 | `1.458` |

生成器里的「行距 %」字段写的就是这个百分比：`105` = 105% = 1.26× 字号。

**常见错误**：想要 1.5 倍行高，写了 `LineSpacing: 150` / `line_spacing = 1.5`，
实际得到 1.8 倍，整块文字松垮。

## 3. 对齐：`just` 对中文无效，要拉伸用 `dist`

同一段文字（10 字，1.6 in 框，折成两行）：

| 对齐 | 每行实测宽 |
|---|---|
| `l` 左对齐 | 100.0 / 100.0 |
| `just` 两端对齐 | 100.0 / 100.0 ← **没变化** |
| `dist` 分散对齐 | 115.1 / 115.1 ← 撑满框宽 |

结论：中文正文用 `l`；真要撑满用 `dist`。`just` 白设。

## 4. 避头尾：PowerPoint 不会替你收标点

四组实测，断行位置都不看标点：

| 文本 | 第二行 | 第三行 |
|---|---|---|
| 一二三四五六七。八九十 | 五六七。 | 八九十 |
| 一二三四五，六七八 | 五，六七 | 八 |
| 一二三四五六七八，九十（1.15in 窄框） | 五六七八 | **，九十** |
| 同上 + `hangingPunct="0" eaLnBrk="0" latinLnBrk="0"` | 五六七八 | **，九十**（不变） |

逗号直接落到行首。`a:pPr` 这三个属性可以写入、PowerPoint 也保留
（往返后仍在，只是顺序被重排成 `eaLnBrk latinLnBrk hangingPunct`），
但**不改变断行**——DrawingML 里没有避头尾开关。

所以：**别指望自动避头尾。**

- 标题、金句：自己断行，每行不超过上表的字数。
- 长正文：改句子，别让 `，` 落在行首；或者生成时按「行首禁则」手动切。
- 行首禁则字符：`，。、；：？！）》」』”’%‰℃` 和破折号后半。
- 行尾禁则字符：`（《「『“‘`。

## 5. 中英混排

| 文本 | 实测宽 |
|---|---|
| `中A中A中` | 94.1 pt |
| `中 A 中 A 中`（4 个半角空格） | 117.6 pt |

差值 23.5 pt ÷ 4 = **5.9 pt ≈ 0.3 em / 空格**。
而按字宽相加推算「不加空格」应得 92.4 pt，实测 94.1——只多 1.7 pt，
说明 **PowerPoint 不会自动加中西文间距**。

规则：

- 想要呼吸感就**手动打一个半角空格**（0.3 em），别指望自动。
- 英文短语两侧留空格，句末标点跟着中文：`改一行 HTML，` 而不是 `改一行 HTML,`。
- 数字与单位之间用半角空格：`18 ms`、`4,652 行`、`10 × 5.625 in`。
- **不要给中文正文加字距**（`spc`）。方块字本来就等宽，加字距只会散架。
  字距只给全大写西文 label（8.5pt + `spc="130"`）。

## 6. 字体是两套槽

```xml
<a:rPr lang="zh-CN"><a:latin typeface="Consolas"/><a:ea typeface="微软雅黑"/></a:rPr>
```

- `a:latin` 管西文，`a:ea` 管中日韩，`a:cs` 管复杂文字，顺序固定。
- **python-pptx 的 `font.name` 只写 `a:latin`**，中文会掉回默认字体 → 一行两种字形。
- 手写 oxml 时两个槽都要写（`a:latin` + `a:ea`），漏一个就掉字体。

推荐配对（Windows 必然存在）：

| 场景 | 拉丁 | 中文 |
|---|---|---|
| 正文 | DengXian Light | DengXian Light |
| 标题 | DengXian Light | 微软雅黑 |
| 代码 | Consolas / Cascadia Mono | 微软雅黑 |

## 7. 标点与数字

- 全角标点：`，。？！；：、` `“”‘’（）《》`
- 半角只在英文/数字语境：`1,000`、`45%`、`18 ms`
- 省略号用 `……`（六点，占两个字宽），不是 `...`
- 破折号用 `——`（两个字宽），不是 `--`
- 数字统一用等宽（Consolas），表格里数字右对齐
- `45%` 还是 `45 %`：选一个，**整份文档统一**，别一半一半

## 8. 字号下限

10 × 5.625 in 画布、投影场景：

| 用途 | 下限 |
|---|---|
| 正文 | 14–15 pt |
| 注释 / 页脚 | 12 pt |
| 小字 label | 8.5 pt（只放编号、短单词，且加字距）|
| 表格 | 10 pt |

中文低于 12pt 在投影上基本读不清。**宁可删内容，也别缩字号。**

## 9. 代码

```python
from pptx.oxml.ns import qn

def set_cjk(run, name="微软雅黑"):
    """python-pptx 只写 a:latin，中文必须补 a:ea。"""
    rPr = run._r.get_or_add_rPr()
    for tag in ("a:latin", "a:ea", "a:cs"):
        el = rPr.find(qn(tag))
        if el is None:
            el = rPr.makeelement(qn(tag), {})
            rPr.append(el)          # 顺序必须是 latin → ea → cs
        el.set("typeface", name)
```

```python
p.line_spacing = 1.25          # 浮点 = 百分比，1.25 → spcPct 125000 → 1.5× 字号

p.alignment = PP_ALIGN.LEFT    # 中文用左对齐；要撑满用 DISTRIBUTE
```

## 10. 预测校验

上面两套公式是**可预测**的，不是事后拟合。反向验证过：

| 设定 | 预测 | 实测 |
|---|---|---|
| 15pt + `spcPct=100000` | 18.00 pt/行 | 18.00 |
| 15pt + `spcPct=125000` | 22.50 pt/行 | 22.50 |
| 15pt + `spcPct=145833` | 26.25 pt/行 | 26.28 |
| 54pt 汉字 × 11，框宽 8.9in | 1 行（594 ≤ 640.8） | 1 行 |
| 54pt 汉字 × 13，框宽 8.9in | 2 行（702 > 640.8） | 2 行 |

排完之后如果想核对，就量 `TextRange.BoundHeight / Lines().Count`，和预测比。
